funniest-excuse is a tiny program that writes one one-line excuse to a file: the excuse an AI agent gives its human after failing a task. The agent was waiting for a loading spinner to finish; the spinner is still spinning, and by now the agent has named it Gerald. The line is 94 characters long, short enough to say in one breath.

## Run it

```sh
python3 main.py
```

It writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
